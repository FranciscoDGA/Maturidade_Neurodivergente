## 📐 Estrutura de Conteúdo

### 1. **Introdução** (100-150 palavras)

**Formato**:
- Hook emocional ou pergunta relevante
- Contexto do problema
- Por que este artigo importa
- O que o leitor aprenderá

**Exemplo**:

> Você se sente diferente? Como se seu cérebro funcionasse de um jeito que ninguém entende? Você não está sozinho. Bilhões de pessoas são neurodivergentes, mas a maioria cresce sem saber o que isso significa.
>
> Neste guia, vamos entender **neurodiversidade** de forma simples e acessível — sem jargão científico, apenas clareza.

### 2. **TL;DR (Too Long; Didn't Read)** (50-100 palavras)

**Antes do conteúdo principal**, incluir um resumo rápido:

```
**Resumo Rápido** 📌
- Neurodiversidade = variação natural do cérebro humano, não deficiência
- Inclui: autismo, TDAH, dislexia, e outras diferenças neurológicas
- Impacto: afeta como você aprende, trabalha, se relaciona
- Ação: conhecer-se é o primeiro passo para viver bem
```

### 3. **Seção Principal 1** (400-600 palavras)

**Estrutura**:
- H2 com keyword variada
- 1-2 parágrafos de contexto
- Bullet points com destaques principais
- Subseções (H3) se necessário
- 1-2 exemplos práticos

**Exemplo (H2)**:
```markdown
## O Que Exatamente é Neurodiversidade?

[Contexto]

- **Ponto 1**: Explicação clara
- **Ponto 2**: Aplicação prática
- **Ponto 3**: Por que importa

### Exemplo Prático
[Um cenário real]

### Mito vs Realidade
| Mito | Realidade |
|------|-----------|
| ... | ... |
```

### 4. **Seções Intermediárias** (2-4 seções)

Cada uma com 300-400 palavras:
- Título descritivo (H2)
- Contexto (1-2 parágrafos)
- Pontos principais (bullets ou H3)
- Exemplo ou aplicação prática

### 5. **Seção de Ação** (200-300 palavras)

**H2**: "Como Isso Afeta Você Hoje"

- Reflexão pessoal
- Exercício prático
- Journaling prompt
- Primeira ação

**Exemplo**:
```markdown
## Como Implementar Isso

**Exercício de 5 Minutos**:
1. Pense em uma situação em que você se sentiu diferente
2. Reflita: pode ser neurodivergência?
3. Anote 3 padrões que você notou
4. Compartilhe com alguém de confiança (opcional)
```

### 6. **Conclusão** (150-200 palavras)

**Estrutura**:
- Resumo dos pontos principais (2-3 linhas)
- Mensagem esperançosa/empoderada
- Próximo passo claro
- CTA (call-to-action)

**Exemplo**:

> Ser neurodivergente não é um erro. É apenas **diferente**. E diferentes pode significar criativo, apaixonado, inovador.
>
> Seu primeiro passo? **Conhecer-se**. Explorar suas padrões. Aceitar seu jeito único de funcionar.
>
> **Próximo artigo recomendado**: [Link para artigo relacionado]

## 🎨 Formatação de Acessibilidade

### Tipografia

```markdown
# Título Principal (H1)
## Subtítulo (H2)
### Sub-subtítulo (H3)

**Negrito** para termos-chave
_Itálico_ para ênfase

- Lista com bullets para itens relacionados
1. Lista numerada para passos
```

### Destaque

```markdown
> Citação ou destaque importante

**Nota**: Informação adicional

⚠️ Aviso importante
✅ Confirmação/ponto positivo
💡 Dica prática
```

### Sem

❌ Não use:
- Parênteses aninhados
- Parágrafos > 150 palavras sem quebra
- Apenas bullets (misture com texto)
- Linhas > 800px (já resolvido pelo CSS)

## ✅ Checklist Antes de Publicar

- [ ] Título contém keyword no início (max 60 caracteres)
- [ ] Slug é curto e descritivo (max 50 caracteres)
- [ ] Meta description em 150-160 caracteres
- [ ] Excerpt é uma sentença clara (100-150 caracteres)
- [ ] Conteúdo tem 1500-2500 palavras
- [ ] H2 usado para seções principais (3-5 seções)
- [ ] H3 usado para sub-seções (1-2 por H2)
- [ ] Mínimo 3 links internos para artigos relacionados
- [ ] Nenhum parágrafo > 150 palavras
- [ ] Pelo menos 1 tabela ou lista com bullets
- [ ] Exemplo prático ou case incluído
- [ ] Readability score: A ou A+
- [ ] Alt text em todas as imagens
- [ ] Sem animações ou autoplay
- [ ] Keyword principal aparece 3-5 vezes
- [ ] Keywords secundárias aparecem 1-2 vezes

## 📈 Métricas Esperadas

- CTR mínimo: 3-5% do SERP
- Tempo na página: 3-5 minutos
- Scroll depth: 60%+
