## 🔍 Otimização SEO

### Estrutura de URL
```
/blog/{slug}
Exemplo: /blog/neurodiversidade-guia-iniciantes
```

### Meta Description
**Fórmula**: [Principal Benefit] + [Número/Adjetivo] + [CTA]

**Exemplo**:
- ❌ "Este artigo fala sobre neurodiversidade"
- ✅ "Descubra o que é neurodiversidade e como ela afeta sua vida. Guia completo com 10 conceitos essenciais"

### Títulos (H1)
**Regra**: Incluir palavra-chave no início, máx 60 caracteres

✅ Bons:
- "Neurodiversidade: O Guia Definitivo para Iniciantes"
- "TDAH em Adultos: Sinais, Desafios e Soluções"

❌ Ruins:
- "O Guia Definitivo sobre Neurodiversidade para Iniciantes"
- "Como Lidar com TDAH Sendo Adulto"

### Subtítulos (H2, H3)
Variar a palavra-chave:

```
H1: Neurodiversidade: O Guia Definitivo
H2: O que é neurodiversidade?
H2: Tipos de neurodivergência
H3: TEA (Transtorno do Espectro Autista)
H3: TDAH
```

### Links Internos
**Estratégia**: Conectar posts relacionados

Exemplo (TDAH em Adultos):
- Link para: "Diagnóstico de TDAH em Adultos"
- Link para: "Maturidade Emocional com TDAH"
- Link para: "Carreira para Pessoas com TDAH"
